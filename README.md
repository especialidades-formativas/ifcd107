# IFCD107 · Especialista en Inteligencia Artificial · Recursos del libro

Material complementario del libro para la especialidad formativa IFCD107. Cada código QR del
libro lleva a uno de estos recursos:

- **Ejecuta**: cuadernos que se abren en el navegador (JupyterLite) o, los que usan
  TensorFlow, FLAML, Gymnasium o FastAPI, en Google Colab.
- **Explora**: herramientas interactivas.
- **Compruébalo**: tests de autoevaluación.

La tabla `recursos.csv` es la fuente única: `herramientas/construir.py` genera la web.
Los cuadernos de Colab descargan sus datos de `contenido/recursos/datos/`, publicados en la web.
El origen y la licencia de cada archivo de datos se explican en el `LEEME.md` de su carpeta.

Web publicada: <https://especialidades-formativas.github.io/ifcd107/>
